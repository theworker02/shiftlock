# ShiftLock v0.9.0 — Health Graph Impact Analysis

ShiftLock v0.9.0 turns runtime health reports into deterministic dependency graphs that can be validated and queried before failover, handoff, quarantine, or lockdown decisions.

## Added

- `health.Report.Validate` for duplicate nodes, missing dependency endpoints, self-dependencies, and dependency cycles.
- `health.Report.Dependents` for deterministic transitive blast-radius analysis.
- `health.Report.Node` for direct named-node lookup.
- Machine-readable `health.ValidationIssue` values with stable issue codes.

## Improved

- `health.Builder.Build` now sorts nodes and edges deterministically.
- Identical runtime state now produces stable JSON regardless of Go map iteration order.
- Dependency direction is documented explicitly: `Edge.From` depends on `Edge.To`.

## Compatibility

- Existing coordination, fencing, workflow, runtime, resource, and backend APIs are unchanged.
- Existing health reports remain source-compatible.
- Go 1.25 remains the module toolchain declaration.

go get github.com/theworker02/shiftlock@v0.9.0
