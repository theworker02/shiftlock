# ShiftLock v0.10.0 — Health Impact Action Planning

ShiftLock v0.10.0 extends the health graph with deterministic blast-radius planning and operator action recommendations when a node fails.

## Added

- `health.ActionKind` constants: `drain`, `quarantine`, `lockdown`, `failover-eval`, `observe`.
- `health.PlannedAction` with node, kind, reason, and priority.
- `health.ImpactPlan` with failed node, blast radius, actions, and validation issues.
- `health.Report.PlanImpact(failed)` for deterministic impact analysis.
- `health.ImpactPlan.Empty()` to detect no-op plans.
- `shiftlock-inspect impact-plan -failed NODE` CLI for JSON impact plans.

## Improved

- Action ordering is stable: priority ascending, then node name, then action kind.
- Upstream dependencies of a failed node receive `observe` recommendations.
- Direct vs transitive dependents receive distinct drain / failover-eval guidance.

## Compatibility

- v0.9.0 health validation and `Dependents` APIs are unchanged.
- Existing health reports remain source-compatible.
- Go 1.25 remains the module toolchain declaration.

## Upgrade

```bash
go get github.com/theworker02/shiftlock@v0.10.0
```
