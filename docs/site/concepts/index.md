# Concepts

| Concept | Meaning |
|---------|---------|
| Claim | Named ownership lease |
| Generation | Process identity competing for claims |
| Fencing token | Monotonic token; stale owners rejected |
| Capability | Narrow, expiring authorization grant |
| Security epoch | Rotation that invalidates prior capabilities |
| Lockdown | Fail-closed emergency stop stronger than maintenance |
| Audit chain | Tamper-evident hash-linked records |

Product standard: protect **who** may work, **when**, and **how** responsibility moves.
