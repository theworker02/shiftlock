# ShiftLock Brand Guidelines

## Positioning

ShiftLock is a **security-first runtime coordination and control module** for production Go systems.

Taglines:

- Coordinate ownership, supervise workloads, enforce runtime policy, and lock down sensitive operations across Go processes.
- ShiftLock protects who may perform sensitive work, when that work may run, and how responsibility moves safely between instances.

## Logo concept

The mark combines:

1. A **shield** — protection and production safety
2. A **lock shackle** — fencing and authorization
3. **Shifted interlocking bars** — ownership handoff between generations

Do not replace the bars with arbitrary icons or add decorative lock particles.

## Color palette

| Name | Hex | Use |
|------|-----|-----|
| Lock Cyan | `#27C2D1` | Primary accent, shackle, gradients |
| Transfer Blue | `#2D72E8` | Secondary accent, handoff motion |
| Deep Navy | `#0A1830` | Shield fill, primary text |
| Secure Teal | `#0B8F8C` | Secondary bar, captions |
| Graphite | `#161B22` | Dark UI backgrounds, mono mark |
| Cloud White | `#F4FAFC` | Light backgrounds, keyhole |
| Warning Amber | `#E5A93D` | Warnings only |
| Critical Red | `#D84A4A` | Critical security states only |

Use flat colors or the restrained cyan→blue gradient on the upper bar only.

## Clear space

Maintain clear space around the mark equal to the height of the keyhole (≥ 8% of mark height) on all sides.

## Minimum sizes

| Asset | Minimum |
|-------|---------|
| Mark only | 16×16 px |
| Horizontal lockup | 120 px wide |
| Stacked lockup | 64 px wide |

At 16×16, prefer `shiftlock-mark.svg` / mono variants. Do not use the wordmark below 80 px width.

## Approved backgrounds

- Cloud White `#F4FAFC`
- White `#FFFFFF`
- Deep Navy `#0A1830` (use white or mono-inverted mark)
- Graphite `#161B22` (use white mark)

## Variants

| File | When to use |
|------|-------------|
| `shiftlock-mark.svg` | App icons, favicons, GitHub avatar |
| `shiftlock-primary.svg` | Docs headers, README |
| `shiftlock-horizontal.svg` | Nav bars, wide headers |
| `shiftlock-stacked.svg` | Square promotional tiles |
| `shiftlock-wordmark.svg` | Text-only contexts |
| `shiftlock-monochrome.svg` | Single-color print / etching |
| `shiftlock-white.svg` | Dark backgrounds |
| `shiftlock-black.svg` | Light single-color contexts |

## Incorrect use

- Do not stretch, skew, or rotate the mark
- Do not recolor bars independently outside the palette
- Do not add drop shadows, glows, or 3D bevels
- Do not place the mark on busy photography without a solid scrim
- Do not claim “perfect distributed lock” in adjacent marketing copy
- Do not use Critical Red or Warning Amber in the logo itself

## GitHub

- Avatar: `shiftlock-mark.svg` on Deep Navy or Graphite
- Social preview: use horizontal lockup on Deep Navy with Cloud White wordmark

## Documentation headers

Prefer `shiftlock-horizontal.svg` at ~180–240 px wide with Cloud White or white page background.
